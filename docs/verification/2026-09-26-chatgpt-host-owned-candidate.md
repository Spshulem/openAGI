Implementation: `src/chatgpt-host-oauth.js`, `src/chatgpt-secret-store.js`, `src/chatgpt-host-provider.js`, `src/chatgpt-host-routes.js`, with explicit factory branch in `src/model-provider.js`, setup settings in `src/setup-wizard.js` and administrative wiring in `src/hosted-interface.js`. `auto` does not select this subscription. The direct provider reports unconfigured and refuses generation and direct transport calls absent a qualification explicitly injected by a local synthetic test; no production composition supplies one. The wizard disables its selection, and setup/admin saves reject it even if a token is present. Only OpenAGI's `ToolRegistry.invoke` executes tools; the backend receives function definitions and outputs but never a Codex-managed tool session. The proposed transport pins the HTTPS ChatGPT product Responses path, rejects redirects, requests `store:false`, and rejects incomplete/duplicate terminal events before publishing text. A terminal `response.completed` is not released until the stream reaches EOF or the protocol's `[DONE]` marker; frames after `[DONE]` are outside that boundary. Tool calls with duplicate IDs, replays across hops, malformed arguments, or disagreement between streamed and terminal items—including an explicitly empty terminal output—are rejected before the affected effect. Encrypted reasoning from a completed hop is forwarded only within one turn's fixed model, credential principal and shared revocation generation; a changed account or credential epoch stops the next request before replay. Device login rotates that shared epoch even for a new grant to the same account. A completed delta-only response without a final message item is not promoted to answer text: it is discarded and may trigger a tool-free retry. An explicitly empty terminal output array remains authoritative, and contradictory terminal `output_text` is rejected before publication. The host checks the bound principal and credential generation immediately before each tool effect and again before publishing final text. Credential binding, call-ID replay ledger and per-hop model reports stay in private WeakMaps outside handler context; each tool receives a fresh context copied from the turn's original authority so one handler cannot grant confirmation, relax scrutiny or specialist scope, or replace the cancellation signal for the next. Cancellation is rechecked after asynchronous reads and before publishing final text. The offline default for this route is `gpt-5.4` based on Hermes's curated fallback, not a claim of account entitlement; the earlier default was listed by Hermes as retired for the ChatGPT OAuth backend. The provider separates `modelRequested` and `modelReported` (null absent a matching terminal response model), and `reasoningEffortConfigured` from `reasoningEffortEffective:null`; subscription usage is not entered as API-key USD cost.
