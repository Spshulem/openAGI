# OpenAGI 0.0.23 review and release candidate

Reviewed stack: PR97 voice review/progress, PR98 proactive inbox/coding watches,
PR99 consented lifelog. Corrections are consolidated on PR99; deploy only the
complete stack, not the intermediate PR98 head.

Review fixes: participant-consent withdrawal immediately pauses capture; late
consent responses are revoked. Inbox Back preserves listening; invalid agent
input preserves polling; Home redraws the inbox indicator. Notification
eligibility is checked without consuming delivery state, then acknowledged after
presentation. Due tasks are filtered before the final feed cap; email drafts
are classified from the canonical draft. Existing PR99 batching and enrollment
enumeration fixes were verified against the earlier PR98 comments.

Lifelog mutations and paid analysis settings are owner-only. Filtered exports
exclude unrelated labels, followups and linked titles. Reads no longer rewrite
the persistent store. Recall merges devices by recency before limiting output
and returns matching transcript evidence. Digests cover matching conversations
independently of the detail page (maximum 200, truncation metadata included).
Cancellation clears active-review status.

Tests use temporary state and synthetic transcripts, no paid model requests.
Focused backend, HTTP and DOM regression checks and assembled-client Vitest
checks passed during review. Release packaging runs on buildbot3/GitHub, not
the laptop. Public Mac release remains gated on signed/notarized artifact
publication; a tag is not installation proof.

G2 stays at the unshipped 0.4.5 version. Recording, notifications, screen context
and paid analysis remain opt-in. Physical acceptance still requires installing
the new G2 bundle, verifying live speech, transcript review/send/follow-up,
inbox Back while listening, immediate consent-off, and lock/background behavior.
No computer-control safety gates or node roles are relaxed by this release.
