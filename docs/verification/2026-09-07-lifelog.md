## Limits and physical acceptance

- Live diarization means anonymous speaker separation, not reliable voice identification across recordings. Labels are user corrections and scoped to a capture stream. Buffered OpenAI transcription retains unknown speaker identity and approximate capture times.
- Moment segmentation is heuristic plus user correction; AI review proposes meeting/topic/action beats rather than silently rewriting the original timeline. Related-moment links currently use shared topics and explicit labels, not a general-purpose knowledge graph.
- Search is text/topic/label/date based, not a new embedding index. The canonical transcript stays in main's private G2 memory store; the owner lifelog and scoped recall tool provide access without duplicating text into screen indexes and complicating deletion.
- History is bounded to 20,000 final segments per device and configured 1/7/30-day retention. Moments are capped to 40 segments/16,000 text characters; user merges cannot remove these safety bounds. Full-history export is bounded by the stored history.
- No visual desktop/mobile screenshot verification, live model quality evaluation, or physical G2 validation was performed. The browser-control execution tool was unavailable; DOM+HTTP tests cover interactions but not layout.
