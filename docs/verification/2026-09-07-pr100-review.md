# PR 100 review and release fixes

Reviewed the full PR against the minimal-lifelog scope and all seven GitHub
review threads. All seven findings were reproduced or confirmed in source and
fixed with regression coverage:

1. Foreground exit discards manual capture state, not only microphone resources.
2. Failed retention grants stop listening if Start lifelog opened it.
3. Wake opt-in restarts capture, invalidating buffered and live pre-opt-in speech.
   Errors from invalidated buffered work cannot stop the replacement session.
4. Opening a saved answer preserves ambient capture and consent. The same applies
   to starting a new conversation while listening.
5. Hidden boot renders paired Home without silently starting microphone capture.
6. Older/Previous use the submitted search, including navigation back to page one.
7. Failed live/buffered manual startup resumes the previous ambient session, or
   shows the existing explicit paused/error state if recovery itself fails.

Additional release prerequisite: Dockerfile copies scripts into its runtime
image, but .dockerignore excluded that directory. Removed the contradictory
exclusion; remote release workflow remains the image validation gate.

Validation: 105 client tests across 16 files and TypeScript pass. The 24 focused
main proactive/lifelog tests pass using isolated state. No live audio, paid model
work, real tasks or personal transcript content were used in testing.

Release versions: OpenAGI 0.0.24, G2 Agents 0.4.8. The previously delivered 0.4.7
artifact is not overwritten. Signing/publication, server installation, Hub
upload, and physical glasses acceptance must each be verified separately.

No remaining blocking code findings in the reviewed changes. Physical gesture
and microphone behavior remain hardware acceptance risks; use the checklist in
2026-09-07-minimal-lifelog-ux.md after installing the updated bundle.
