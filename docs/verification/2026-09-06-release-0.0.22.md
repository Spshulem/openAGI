# OpenAGI 0.0.22 release reconciliation

PR 91 consolidates G2 work with the preserved histories of PR 92 (daemon
recovery) and PR 93 (coding supervisor). Native overlap is the approval fetch
timeout; both full approval display and outage recovery are retained. Computer
readiness diagnostics from PR 93 are retained alongside G2 hosted routes.

The release fixes an otherwise broken fresh-install boundary: Mac and Docker
packages now install locked production dependencies (`ws`) and include the
supervisor adapter. Source installation and updating install dependencies before
starting/restarting services. The G2 package stays at 0.4.2.

Verification used an isolated buildbot3 directory and temporary runtime data.
The broad Node discovery run passed 1,120 backend tests; it also incorrectly
discovered 14 Vitest client files. The npm command now explicitly selects backend
test files. The cron timeout fixture uses private storage, and the node-roster
regression verifies that rejected heartbeat data never replaces an enrollment.
Those 15 regression tests passed twice. The identical G2 source previously
passed 65 client tests, TypeScript, Vite packaging and the packaged-secret scan.

The original development checkout was not reset, cleaned or blanket-staged.
Release reconciliation used a separate worktree. Full publication history passed
the Git safety guard. An optional workflow-test gate could not be pushed with the
current GitHub credential's scope; it is retained only on a local branch, not in
this release. The existing tag-triggered Mac and Docker workflows are unchanged.

Tagging starts artifact generation; it does not prove signing, notarization,
installation, BLE behavior or physical G2 follow-up gestures. Existing desktop
sessions are discoverable/readable, not automatically reply-capable.
