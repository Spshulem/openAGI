# OpenAGI 0.0.61 release candidate

This patch combines the reviewed iMessage cursor, signal-memory preservation,
correction-lineage, and fleet scan-cache fixes on main. Mobile routing/onboarding
and native Linux Wayland work remain outside this release.

Pre-release acceptance requires current-head runtime/G2 verification, portable
runtime packaging and startup smoke tests, and native Mac tests. Public release
acceptance additionally requires signed/notarized Mac assets, the matching Sparkle
appcast, G2 packages, portable runtime archives and checksums, and an isolated
runtime smoke test of the published artifact. A successful build does not prove
installation or live account/device integration behavior.
